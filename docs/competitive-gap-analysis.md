# تحليل المراجع والفجوات — BUOD

آخر تحديث: 2026-08-18

## القرار المنتجـي

BUOD ليس مكتبة موديلات عامة. المنتج الأساسي هو **سجل منتج إنشائي موثّق للسوق السعودي** يجمع ملف BIM/3D، المواصفات، المورد، السعر، التوفر، الترخيص، والرقم المرجعي BUOD في مكان واحد.

- **BIMobject** هو المرجع الأقرب لبنية المنتج والبيانات.
- **3D Warehouse** مرجع لتجربة البحث والتنظيم والتكامل مع SketchUp، وليس مصدر محتوى يعاد نشره.
- **1miba** مرجع لعمق التصنيفات، المواد، التشطيبات، المشاهد الجاهزة، والبحث بالصورة.
- **Meshy** تكامل اختياري لإنشاء مجسم مفاهيمي من صورة أو نص؛ ناتجه لا يُعامل تلقائياً كعائلة Revit أو BIM موثق.

## مصفوفة القدرات

| المرجع | ما نأخذه كفكرة | ما لا ننسخه أو لا نعتمد عليه |
|---|---|---|
| BIMobject | صفحات المصنع والمنتج، تعدد الصيغ، المواصفات والشهادات، التوفر حسب السوق، التحليلات، الربط مع Revit | بناء نسخة عالمية عامة بلا تميّز محلي |
| 3D Warehouse | بحث نصي وبالصورة، فلاتر تقنية، إحصاءات النموذج، المفضلة والمجموعات، كتالوجات المصنع، رفع جماعي | تجميع أو إعادة بيع موديلاتهم؛ شروطهم تمنع تجميع المحتوى في موقع آخر |
| 1miba | شجرة تصنيفات عميقة، مواد وTextures وإضاءات، مشاهد كاملة، فلترة حسب النمط، مجاني/VIP | الاعتماد على محتوى غير واضح الترخيص أو نقله إلى BUOD |
| Meshy | صورة/نص إلى مجسم، تعدد صيغ التصدير، تحسين Mesh وPBR، API مع مهام غير متزامنة | وصف الناتج بأنه BIM هندسي أو مطابق لمنتج مصنع دون مراجعة واعتماد |

## الفجوات حسب الأولوية

### P0 — أساس موثوق

- بحث بالاسم العربي والإنجليزي ورقم BUOD والعلامة والطراز.
- فلترة بالفئة والمورد.
- إظهار الصيغ والبرامج وعدد الملفات قبل فتح المنتج.
- صفحة منتج تعرض المواصفات، المواد، السعر، التوفر، مدة التوريد، الترخيص، وحقوق الاستخدام.
- ملفات خاصة بروابط مؤقتة، مع تسجيل أحداث المشاهدة والتنزيل.
- منتجات مشابهة وربط مباشر بنافذة المورد.

### P1 — جاهزية كتالوج احترافي

- فلاتر خادمية للصيغة، البرنامج والإصدار، المادة، المصنع، بلد المنشأ، التوفر، ودرجة التوثيق.
- تصنيفات فرعية عميقة ومسارات تصنيف واضحة.
- حقول BIM تقنية: LOD، الوحدات، الأبعاد، عدد المضلعات، حجم الملف، ونسخة البرنامج.
- شهادات وDatasheets وEPD والاستدامة وتصنيفات IFC/OmniClass/Uniclass عند توفرها.
- كتالوجات ومجموعات ومفضلة ومقارنة منتجات.
- رفع جماعي CSV للموردين مع تقرير أخطاء قبل النشر.
- لوحة تحليلات للمورد: الظهور، المشاهدات، التنزيلات، والطلبات.

### P2 — اكتشاف وتكاملات التصميم

- بحث بالصورة لإيجاد منتجات مشابهة، لا لتوليد منتج جديد.
- عارض GLB داخل صفحة المنتج مع إحصاءات النموذج.
- إضافة SketchUp/Revit لاحقاً للوصول إلى مكتبة BUOD من داخل البرنامج.
- طلب منتج أو ملف غير متوفر من المورد.
- API آمن للشركات ومكاتب التصميم.

### P3 — BUOD AI Lab

- صورة واحدة أو عدة صور إلى مجسم مفاهيمي عبر Meshy API.
- فصل واضح بين: **AI Concept**, **BUOD Reviewed**, و**Manufacturer Verified**.
- عدم نشر الناتج حتى يؤكد المستخدم حقوق الصور ويختار الترخيص.
- مراجعة بشرية وتهيئة هندسية قبل تحويل الناتج إلى BIM قابل للاعتماد.
- حفظ تكلفة المهمة، حالتها، صيغ المخرجات، وإشعار المستخدم عند الاكتمال.

## تميّز BUOD في السعودية

- أسعار بالريال مع تاريخ آخر تحديث.
- توفر ومدة توريد حسب المدينة والمنطقة.
- موردون ومصنعون محليون موثقون.
- دعم عربي/إنجليزي كامل.
- شهادات SASO/SABER وملاءمة كود البناء السعودي عند انطباقها.
- رقم BUOD ثابت يمكن ربطه مستقبلاً باستخراج BOQ من Revit.
- فصل بيانات المنتج عن ملفات التصميم حتى تبقى المواصفات قابلة للبحث والمقارنة.
