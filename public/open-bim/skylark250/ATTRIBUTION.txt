This website directory distributes the derived WALL-M.glb preview and rights notices.
Original files are retained without changes in the downloadable product package,
available from /blocks/open-bim-skylark250-wall-m, and at the upstream source above.
This is an older library release, not the latest Skylark 150 system.

BUOD modifications to derived files:
- Extracted the WALL-M element, GUID 1moQZArJLBpxzAuCd9xIcx, from the original IFC4 library using IfcOpenShell 0.9.0.
- Removed an empty presentation-layer assignment produced by subset extraction.
- Produced a GLB geometry preview and an orthographic raster preview from the extracted IFC geometry.
- The IFC geometry, GUID, properties and original IfcColumn classification were retained; we did not assert that this classification is correct for a wall.
- Preview display colours are not a verified physical material specification.
- The interactive viewer translates the preview to its studio origin without changing scale or geometry, and applies studio lighting.
- WALL-M-render.jpg is a studio render of that same GLB, with illustrative neutral clay shading, edge emphasis and lighting. It is not a verified material or finish. Reproducible render: tools/bim-render.html in BUOD source.
